# Offline pose-source evidence

Dev-only standalone `/dev-fixtures/audit-pose-inspection/index.html`, not a production entry. Defaults to agent opt-out; external connections are blocked by CSP. Explicit buttons load saved project names, inspect selected move/directions and download evidence. No HTTP client, queue/bootstrap, credentials or data mutation is used. Original provider inputs/results are verified by PNG SHA256 and exact selected provenance/request/job identity. Only done comparable requests with equal params apart from seed can join the comparison; all output indices must be complete. Stored request params must also match the selected item's original keyframe and the current requested clip poses. Raw frames are unrotated into logical cell order with the same pure helpers as production. Extracted/pre-postprocess layers, per-roll QA and differences against the currently stored item are preserved. This is evidence, not automatic repair or acceptance.

From app/: `npx vitest run test/unit/pose-inspection.test.ts`; `npx tsc -p dev-fixtures/audit-pose-inspection/tsconfig.json`.

The visible **Inspect original body cleanup** button separately verifies the move source's body provenance, request hash, rest pixels and exact frame sequence; exports original, normalized/largest-component processed and removed pixels for each known-complete body roll. Matching stored pixels identifies the saved candidate without assuming the last roll won. It does not generate, retarget, estimate, accept or mutate anything.

**Inspect pending move results** separately binds the exact persisted studio-move project/seed/versioned intent to known-complete raw body requests, then verifies cleaned PNG bytes against each matching estimator request. It exports raw/cleaned/requested/actual-measured boards and failed input PNGs. Missing, lost or malformed measurements remain missing; no body is recovered or published and no request is resent.

For a complete original candidate whose sole failure is palette fit, the pending inspector additionally shows the fixed near-rest-v1 colour preview. Original failed QA and measurements stay separate. Changed PNGs require their own exact-hash completed estimates; missing checks remain null and final QA is withheld. The preview never publishes, retries or spends.
