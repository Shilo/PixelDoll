# PixelLab contract snapshots

`pixellab-openapi-v2.json` is the historical October 20, 2026 snapshot. Preserve it as the contract used by those experiments.

For managed custom `POST /characters/animations`, the [November 2 capture](2026-11-02-managed-custom-v3-contract.json)
supersedes the old template-only skeleton-v3 description. Without `template_animation_id`, `mode:skeleton-v3` can create
text-described shared motion, with later directions using `animation_group_id`. The [starter experiment](../2026-11-02-eight-direction-starter-pack.md)
records the tested implementation and limits. This is not proof of REST parity for MCP's explicit pose/move/scale fields.

The full snapshot has not been silently replaced or represented as current. These dated files do not establish future
pricing, supported plans, authoritative timing/pivots, or artistic quality. No fresh API request was made for this note.
