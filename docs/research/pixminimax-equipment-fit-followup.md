# Qualify equipment fit on PixMiniMax and Skeleton V3

This is deferred research, not a release blocker or a request to change the PixMiniMax default. The [animation model audit](2026-11-19-animation-model-audit.md) records the original evidence: both body routes passed both Walk cap checks; on one matched eight-frame Slash, the same coat failed on PixMiniMax and passed on Skeleton V3 in both east and south. Body plus coat cost 9.6 versus 13.6 generations, excluding setup. The sword never qualified as a shared standing reference in east, so those results say nothing about comparative sword alignment. The cost advantage is measured on those runs, not assumed at other sizes or frame counts.

## Fixture and test order

1. **Qualify the standing items first.** Use one rig-ready 64 px character with independently rendered east and south views. Reuse the exact standing coat and main-hand sword across arms. Require a clear standing right-hand grip and a clean extraction in each tested view. Record wrong hand, unclear grip, and stray pixels separately. If east cannot qualify, record an upstream setup failure. A south-only run can inform south, but cannot stand in for an east result. Do not spend on the unmatched arm to fill a gap.
2. **Run the matched sword test.** Start with eight-frame, empty-hand Slash in east and south, one fixed seed per route, the same canvas and action intent, the same reviewed sword, and production workflows. Allow route-appropriate body prompts or authored poses, but record them before running and keep them fixed through the block. The body routes differ; both equipment arms use Skeleton V3 and the production joint and extraction pipeline. A synthetic or mirrored direction is not a second independent view. Do not combine earlier unmatched results with this block.
3. **Replicate coat and sword before generalizing.** Repeat the coat Slash case on a second body proportion and a second seed. Include a less occluded action such as Walk as a control. After short clips qualify, test a mutually supported longer count, such as 12 frames, at the same playback duration. Separately test one PixMiniMax-only count above 15 for visible jumps across Skeleton V3 equipment batches; report it as a stress case, not a matched result. Expand to additional independent facings only if the first blocks can answer the question.
4. **Isolate the Text V3 headwear failure.** Replay the retained six-frame Cast check data, if available, or match an approved headwear case. Separate estimated-head drift, loss of the extraction colors, and genuine missing or misplaced hat pixels. Do not lower existing thresholds or attribute the failure to frame count without evidence. Keep Text V3 data separate from the PixMiniMax versus Skeleton V3 comparison.

## Score and diagnose

- Review body-only playback and fitted composites separately, with model labels hidden and the same frame timing. Inspect every frame at pixel scale. Score correct-hand grip, ambiguous or occluded grip, grip slip relative to the visible hand, wrong depth relative to limbs, coat holes, stray pixels, and visible discontinuities at equipment batch boundaries. Record disagreement rather than counting an unclear grip as either a pass or a wrong hand. Score loop interpolation separately; raw loop seams are not an equipment-fit metric.
- Record existing production QA by direction and item, expected and received frame counts, the worst failing frame, and the stage where each failure starts: standing item, native body or measured joints, equipment render, or extraction. Backing-color retention is an extraction diagnostic, not a direct measure of garment coverage. Compare it with what reviewers see before recommending a fix.
- Use the same published gate for both arms. A matched view passes only if the relevant production item checks pass and reviewers see no wrong hand, unacceptable slip, missing cloth, or incorrect layering. Report pass counts and unscorable counts separately. Report actual generations and dollars for setup, body, measurements, items, and retries, plus total cost per accepted fitted direction. A cheap failed result is not a cost win.
- If a case consistently fails on PixMiniMax but passes on Skeleton V3, identify the failing action, direction, item class and observable cause. This supports a contextual recommendation, not an automatic model switch, charge, or publish. If both fail, investigate the shared fitting or extraction stage before changing model advice. If the difference does not repeat, keep the result qualified to the tested case. Do not claim general parity from one fixture.

## Spending and deliverable

Check approved balance and outstanding receipts before dispatch. Quote setup and comparison separately, use a fresh explicit ceiling for any future block, and check it before each request. Stop on an ambiguous charge or interrupted submission; recover by exact job ID without repeating the paid request. Do not spend on an unqualified fixture, automatic retries, or a rig that cannot be matched.

Add a data-only report to the audit with fixture and seed IDs, canvas, directions, frame counts, model and route choices, QA and blind-review outcomes, actual costs, and one recommended next action. Record where evidence is missing. Do not save or commit generated images, credentials, or private request payloads.
