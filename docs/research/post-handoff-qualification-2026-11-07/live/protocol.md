# Endpoint-dressing feasibility pilot

Prepared before submission on November 7, 2026. This tests a necessary fixed-body constraint of the new endpoint-dressing hypothesis, not a new default or a demonstrated savings claim.

Run `prepare.mts` with the pinned Node version from the repository root. It reads existing public bench-derived item packets; regenerate missing packets using `app/scripts/item-trial-packets.ts` from `app/`. It writes a public-input plan and a browser-only research page into ignored `app/test-results-post-handoff-live/`. The page reuses the application's queue, exact request hashing, Agent connection and stored result blobs. It records a durable claim before each enqueue, retains failures, and never automatically resubmits an unknown outcome.

## Fixed design

- Two existing body/item fixtures, south and east, native 64 and 80 pixel cells.
- Eight requests: four fixture/view cases, each with plain dressing and the same prompt plus cloth-settling language. One fixed requested seed per pair; equal seeds do not establish shared random noise.
- `/animate-pixminimax`, eight frames, no supplied last frame. Input is a two-cell image: keyed frozen body on the left, its approved garment-only layer on the right at the same pixel scale.
- Only provider frame index 7 is the acceptance candidate. Keep all eight images and inspect drift throughout. No best-frame selection, rescaling, recentering, translation search, or automatic repair before evaluation.
- Require eight outputs with the full submitted canvas dimensions before cropping the fixed left-hand cell. Measure right-panel residue separately.
- Compare source garment palette, outline, distinctive details, location, body-key witnesses, raw body deviations and extracted equipment. Evaluate the final frozen-body recomposition separately so recomposition cannot conceal bad raw pixels retained as gear.

The approved garment already fits this body. Exact free overlay is therefore the zero-cost golden control. Success here cannot prove cross-body fitting, novel garment design, cloth simulation, better quality than overlay, or lower cost than current dressing. This intentionally easy cohort can falsify fixed-body fidelity before more demanding experiments buy additional samples. Existing edit/transfer receipts are context only, not contemporaneous matched price/quality controls.

Different drape can legitimately change silhouette; report golden-mask differences rather than declaring every changed clothing pixel incorrect. Independently review ambiguous clothing ownership, motif and shape after the numeric checks. Key colors and exposed skin do not by themselves establish pixel ownership.

## Execution and evidence

Use a separate loopback Agent-mode origin for live requests while keyless browser tests use their own origins. The research page displays exact request identities and requires an explicit paid submission click. No private assets or credentials appear in its plan, evidence export, screenshots, or report. Record confirmed provider charges and unresolved outcomes separately; a balance delta is not the billing ledger.

Retain exported plan, claims, receipts, provider-order PNGs and hashes in ignored evidence. Commit reproducible scripts, small measurements, verdicts, limitations and the independent challenge. Reject or defer the method if endpoint body registration, design fidelity or ownership fails; one seed can only establish feasibility or a counterexample, not production qualification.
