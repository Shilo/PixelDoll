## Primary guidance checked online

- [W3C Radio Group Pattern](https://www.w3.org/WAI/ARIA/apg/patterns/radio/): Tab enters/exits the group; arrows move/check options.
- [W3C Keyboard Interface](https://www.w3.org/WAI/ARIA/apg/practices/keyboard-interface/): composite controls use one Tab stop and consistent arrow-key movement.
- [W3C Tabs Pattern](https://www.w3.org/WAI/ARIA/apg/patterns/tabs/): selected tab is in the page tab order; arrow navigation changes focus/selection.
- [W3C Native Modal Dialog Technique](https://www.w3.org/WAI/WCAG22/Techniques/html/H102): native modal focus containment and focus restoration support.
