# Shield validation (2026-10-22)

Scope: `off_hand` shields on existing 4- and 8-direction rigs, idle and walk. No new bodies or motion were generated.

## Offline quality-gate fix

G9 treated every held silhouette as having a meaningful principal axis. A 5×6 mask becoming 6×5 keeps the same area and
most of its shape, but its calculated axis turns 90°. That caused a false failure and could spend credits re-rolling a
consistent round shield. Conversely, concentric filled and hollow masks could have the same calculated axis and escape
G9 despite a large shape change.

`axisOf` now returns no axis for a near-round mask: the covariance eigenvalue gap divided by their sum is below 0.2
(principal aspect ratio below √1.5). Those adjacent-frame pairs use the existing aligned-IoU floor of 0.3. Elongated
items retain the existing 30° limit relative to the forearm; the anchor route still uses IoU.

Three new Vitest regressions demonstrate:

- Near-round width/height variation passes instead of reporting a false quarter turn.
- A large round-silhouette change fails the shape check.
- An elongated item turning 90° against a stationary forearm still fails.

The first two tests fail before the fix and pass afterward. An additional keyless check on saved sword exports found
no G9 failures in 36 Ranger frames and 60 eight-direction frames (idle/walk, generated views).

theme switching and a completed ZIP download. A local developer harness importing the actual item QA functions
passed five visible cases: round-mask variation, a rejected large silhouette change, a rejected blade turn against a

A read-only sub-agent adversarially reviewed the covariance cutoff, tiny masks, forearm motion, retries, regression
coverage and saved evidence. It found one actionable regression: the new fallback treated the existing below-six-pixel

failed. The smallest fix preserves the posed route's existing minimum sample-size skip. The anchor route still uses
IoU, and sufficiently populated near-round masks still receive the new silhouette check. Three parametrized motion
regressions cover five, seven and eleven pixels. The reviewer reported no other actionable findings. The known live
body-occlusion flags remain unresolved; this review does not approve those drafts.
